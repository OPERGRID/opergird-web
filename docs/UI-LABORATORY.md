# OPERGRID UI Laboratory

`/ui-lab` is the production design-system reference. It renders actual components imported from `src/components/ui` and `src/components/layout`. Its CSS is limited to section navigation, documentation grids, labels, and example spacing.

The sections are Foundation, Actions, Form & Input, Navigation, Data Display, Feedback & States, Overlay, Layout, Operational / Enterprise, Responsive, and Production Page Composition.

Review each component in dark and light themes and at 1440, 1280, 1024, 768, and 390px. Check keyboard focus, overlay dismissal and focus return, table overflow, field labels and validation, and the shared select/date geometry. Fix global inconsistency in production styles or components, not with a Lab-only visual patch.
